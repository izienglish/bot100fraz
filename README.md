# Easy-Peasy PDF Bot

Telegram-бот: проверяет подписку на канал @izi_en и выдаёт PDF «100 фраз».

## Файлы
- `main.py` — код бота
- `assets/EasyPeasy_100Fraz.pdf` — файл, который бот отправляет
- `requirements.txt` — зависимости
- `Procfile` — команда запуска для Railway/Render

## Деплой на Railway (бесплатно)

1. Создайте новый **приватный** репозиторий на GitHub (приватный — важно, чтобы токен не утёк, даже если вы его случайно закоммитите) и залейте туда все файлы из этой папки.
2. Зайдите на railway.app → New Project → Deploy from GitHub repo → выберите репозиторий.
3. В настройках проекта откройте вкладку **Variables** и добавьте переменную:
   - `BOT_TOKEN` = ваш токен от BotFather
   (никогда не вписывайте токен прямо в код — только через переменную окружения)
4. Railway сам определит `Procfile` и запустит процесс как worker (не web) — это то, что нужно, отдельный домен/порт не требуется, бот работает через polling.
5. Проверьте логи (Deployments → View Logs) — должна появиться строка «Бот запущен, жду сообщений...».
6. Откройте бота в Telegram и отправьте /start — проверьте обе ветки (без подписки / с подпиской).

## Обновление ссылки в TikTok

После того как бот запущен и протестирован, обновите deep-link на u2l.ai (https://u2l.ai/MiKbT7), заменив цель с
`tg://resolve?domain=izi_en`
на
`tg://resolve?domain=ВАШ_USERNAME_БОТА`
(без @, просто username, например EasyPeasyPdfBot).

## Важно про безопасность токена
Токен бота, который вы мне прислали в чате, теперь известен и в этом чате. Если хотите перестраховаться —
можно в @BotFather выполнить `/revoke` и получить новый токен, а затем уже его использовать при деплое.
